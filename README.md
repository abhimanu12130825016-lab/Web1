# Neon Nest Studios

A launch-ready creative studio website for businesses that want a memorable digital presence.

## Run locally

Open `index.html` directly in a browser, or use VS Code's Live Server extension. The site is static and needs no build step or backend service.

## Included

- Responsive multi-view studio site
- 3D animated hero heading and interactive motion effects
- Portfolio search and category filters
- Review modal with rating breakdowns
- Project application form with success state
- Client portal demos for content, campaigns, reviews, and website preview
- Review replies persist locally with browser storage

Review replies are stored in this browser only. The project application form uses Netlify Forms when deployed to Netlify.

## Deploy with working applications

1. Create a new site in Netlify and deploy the `Web1` folder (or connect the repository).
2. Trigger a fresh deploy after the form markup changes so Netlify can detect `project-application`.
3. Open Netlify's **Forms** section to view incoming applications and configure email notifications.

The form works as a visual demo when opened locally, but local file previews cannot deliver submissions to Netlify. The live Netlify URL is required for real applications.
